# AFTER THAT — Maximalist Digital Flagship

> **"Maximalist digital expression at the bleeding edge of Indian youth culture, cinematic ad films, and cultural IPs."**

Official digital flagship website for **AFTER THAT** ([@afterthat.in](https://www.instagram.com/afterthat.in/)). Conceptualised and engineered with experimental Swiss typography, brutalist editorial layouts, contemporary streetwear aesthetics, and high-fashion art direction.

---

## ✦ Key Architectural Features

- **70mm Shutter Countdown Preloader:** Cinematic opening sequence with system telemetry, animated frame counters, and an electric red wipe transition.
- **Unified Custom Cursor Engine:** Mathematically centered dual-element pointer with spring enlargement, contextual status pills (`VIEW`, `OPEN`, `EXPLORE`), magnetic button snapping, and a floating project thumbnail portal.
- **Synchronized Smooth Scroll:** Lenis smooth scrolling piped directly into GSAP's RAF ticker and ScrollTrigger updates for stutter-free 60 FPS motion.
- **Pinned Horizontal Gallery:** Scroll-driven horizontal film reel with dual-axis parallax typography and hover image enlargement.
- **Interactive Service Accordion:** Five verified studio disciplines with instant visual preview switching and scope breakdowns.
- **Full-Bleed Case Study Drawer:** In-depth project modals detailing production credits, art direction, and high-resolution stills.
- **Synthesized Web Audio Experience:** Zero-asset procedural sound engine powered by the native Web Audio API (tactile clicks, frequency sweeps, sub-bass impacts).
- **Transmission Terminal:** Validated interactive inquiry form featuring interactive budget scopes, live transmission feedback, and celebratory particle confetti.
- **Geographic & Temporal Telemetry:** Live Kerala Indian Standard Time (IST) clock and exact coordinates (`10.0286° N, 77.0605° E`).

## ✦ Getting Started

### Prerequisites

- Node.js 18.17+ or 20+
- npm, pnpm, or yarn

### Installation

```bash
git clone https://github.com/jj9821/Afterthat.in.git
cd Afterthat.in
npm install
```

### Development Server

Run the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build

Create an optimized, statically analyzed production build:

```bash
npm run build
npm run start
```
